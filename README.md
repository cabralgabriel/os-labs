# OS Labs

## overview

This repository contains practical implementations, experiments, and exercises in C (POSIX/Linux) exploring fundamental concepts of Operating Systems.

## repository structure

```text
os-labs/
├── 01-processes/        # process creation
├── 02-threads/          # concurrency, multithreading
├── 03-ipc/              # pipes, message queues, shared memory
├── 04-scheduling/       # cpu scheduling algorithms
├── 05-synchronization/  # mutual exclusion, semaphores and mutexes
├── 06-deadlocks/        # deadlock conditions, detection and prevention
├── 07-memory/           # memory management
├── 08-io/               # i/o subsystem, buffering
└── 09-file-systems/     # file system structures, directories
```

## references
